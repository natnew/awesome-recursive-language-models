# Security Policy

## Scope

`awesome-recursive-language-models` is a curated, documentation-only "awesome list".
It ships **no runtime code** — only Markdown content plus development tooling
(`prettier`, `markdownlint-cli2`, `linkinator`) used to lint and validate the list.
As such, the main security considerations are:

- **Malicious or unsafe links** added to the list.
- **Supply-chain issues** in the development dependencies (tracked via Dependabot).

## Reporting a Vulnerability

If you find a security concern — for example a link that points to malware, a
typosquatted resource, or a vulnerable dependency — please report it privately:

- Preferred: open a [GitHub Security Advisory](https://github.com/natnew/awesome-recursive-language-models/security/advisories/new)
  for this repository.
- Alternatively, open a regular issue **without** sensitive details and request a
  private channel.

Please do **not** disclose exploitable details in a public issue until a fix or
removal is in place.

## Response

We aim to acknowledge reports within 7 days, validate the concern, and remove or
correct the offending content or dependency promptly. Credit will be given to
reporters who wish to be acknowledged.
